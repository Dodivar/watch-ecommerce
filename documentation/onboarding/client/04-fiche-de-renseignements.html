Fiche de renseignements

Les informations dont nous avons besoin pour configurer votre boutique. Rien ici n'est technique : ce sont vos informations commerciales, légales et vos contenus. Le reste — hébergement, base de données, sécurité, mises en ligne — est de notre côté.

Comment la remplir. Répondez directement dans les champs. Votre saisie est conservée dans ce navigateur : vous pouvez fermer la page et revenir plus tard. Quand vous avez terminé — ou même avant — cliquez sur « Télécharger la fiche remplie » et renvoyez-nous le fichier obtenu.

Une case vide n'est pas un problème : elle nous dit simplement qu'il faut en reparler. Écrivez « à voir avec vous » là où vous bloquez, et renvoyez la fiche sans attendre.

🔐 Aucun code Stripe dans ce document. Ni clé publique, ni clé restreinte (rk_live_…), ni secret de webhook (whsec_…), ni mot de passe. Cette fiche circule par e-mail ; ces valeurs, non.

Elles passent par un lien à usage unique créé sur onetimesecret.com/fr, comme l'explique la fiche de transmission, une fois le guide Stripe terminé.
