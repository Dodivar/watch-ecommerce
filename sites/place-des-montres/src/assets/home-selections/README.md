# Images (import Vite) — sélections d’accueil

Option avancée : fichiers ici + `import` dans `sites/place-des-montres/homeSelections.config.js` pour bénéficier du hash et de l’optimisation Vite.

Pour un ajout simple sans toucher au JS, préférez plutôt `sites/place-des-montres/public/home-selections/` (voir README dans ce dossier).
