# Images — section « Nos sélections du moment »

Déposez ici les visuels de la page d’accueil (format portrait recommandé, ratio **4:5**, ex. 800×1000 px).

| Fichier attendu | Carte |
|-----------------|--------|
| `omega.jpg` (ou `.webp`) | Omega |
| `montres-homme.jpg` | Montres homme |
| `montres-femme.jpg` | Montres femme |

Les chemins dans la config sont de la forme `/home-selections/nom-du-fichier.jpg` (servis tels quels par Vite depuis ce dossier `public/`).

Alternative avec optimisation au build : placer les fichiers dans `sites/place-des-montres/src/assets/home-selections/` et les importer dans `homeSelections.config.js` (voir commentaires dans ce fichier).
